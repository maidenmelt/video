# Video Analyser

Автоматический анализ видео приёмов в стоматологических клиниках.

## Что делает

Принимает видео приёма + метаданные, анализирует речь, визуал и метаданные,
выдаёт JSON-отчёт с найденными нарушениями и итогом:
- служебная записка
- ознакомительная записка
- нарушений нет

## Контракт

**Вход:**
- `video.mp4` — видео приёма
- `metadata.json` — метаданные (пациент, врач, клиника, дата)

**Выход:**
- `report.json` — отчёт по приёму
